Datenschutzerklärung (Deutsch)

Keine Datenerhebung

Die Browser-Erweiterung D365 Helper erhebt, überträgt oder teilt keine personenbezogenen Daten – weder mit dem Entwickler noch mit Dritten. Es gibt keine Analyse-, Tracking- oder Werbedienste.

Lokale Speicherung

Alle Eingaben (Favoriten, eigene Tabellen und Klassen, URL-Snippets, Company-Farben, Einstellungen, die D365-Umgebungsadressen mit vom Nutzer vergebenem Typ, Farbe und optionalem Organisationsnamen sowie die zuletzt genutzte D365-Umgebung und die zuletzt genutzten Company-Codes) werden ausschließlich im Browser über die Chrome-Storage-API (chrome.storage.sync) gespeichert. Ist die Browser-Synchronisierung aktiv, synchronisiert der Browser-Anbieter diese Daten mit dem eigenen Google- bzw. Microsoft-Konto des Nutzers.

Ist der Verlauf eingeschaltet (Standard), speichert die Erweiterung zusätzlich die letzten 50 besuchten D365-Seiten (Umgebungsadresse, Company-Code, Menüpunkt und Parameter, Seitentitel, Zeitpunkt) im lokalen Speicher des Browsers (chrome.storage.local). Der Verlauf wird weder synchronisiert noch exportiert und lässt sich in den Einstellungen ausschalten und leeren.

Die optionale Export-Funktion speichert diese Daten als JSON-Datei auf dem eigenen Gerät des Nutzers. Die Erweiterung lädt die Datei nirgendwohin hoch; beim Import wird eine Datei nur lokal im Browser gelesen.

Privacy Policy (English)

No data collection

The browser extension D365 Helper does not collect, transmit, or share any personal data – neither with the developer nor with any third party. There are no analytics, tracking, or advertising services.

Local storage

All user data (favorites, custom tables and classes, URL snippets, company colors, settings, the D365 environment URLs with the type, color and optional organization name the user assigns to them, and the last used D365 environment and company codes) is stored exclusively in the browser using the Chrome Storage API (chrome.storage.sync). If browser sync is enabled, the browser vendor syncs this data to the user's own Google or Microsoft account.

If the history feature is enabled (default), the extension additionally keeps the last 50 visited D365 pages (environment URL, company code, menu item and parameters, page title, time) in the browser's local storage (chrome.storage.local). The history is neither synced nor exported and can be turned off and cleared in the settings.

The optional export function saves this data as a JSON file on the user's own device. The extension does not upload the file anywhere; importing a file only reads it locally in the browser.
